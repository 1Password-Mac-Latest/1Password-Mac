## Have these ready before you open the installer

An hour without interruptions, because the master password deserves undivided attention. A note of which
browser you genuinely use most — Safari, Firefox, Chrome and Opera are all supported, but the first
extension should go where you spend the day. The email address attached to your most important accounts.
And a rough list of the five logins whose loss would ruin a week; those are the ones that get rebuilt
first.

## The list itself

- [ ] Install the application before touching any extension
- [ ] Choose a master password long enough to be safe and human enough to recall unprompted
- [ ] Write that phrase down once, on paper, and store it somewhere physically secure
- [ ] Add exactly one browser extension to begin with
- [ ] Save a single test login and confirm the extension offers it back on the same site
- [ ] Enter one identity record — name, address, contact details
- [ ] Enter one payment card and complete a small real purchase with it
- [ ] Replace the password on your primary email account using the generator
- [ ] Repeat that replacement for the four other critical accounts on your list
- [ ] Install the remaining browser extensions only once the first has proved itself
- [ ] Put the application on the phone, since the contents reach Windows, iOS and Android too
- [ ] Confirm the running build is 8.12.34
- [ ] Read the vendor's pricing page rather than assuming the listed $2.99 month is the only term

## The first hour, in the right sequence

Start with the master password and nothing else. Every other decision is reversible; this one is not, in
the sense that the whole store hangs from it. Then create one test entry and prove the round trip: log out
of a site, return to it, and watch the extension recognise the page and fill the fields. That single
successful cycle is what convinces people to keep going.

Only then reach for the generator. Email is the first account to change, because every password reset in
your life terminates there, and a compromised inbox undoes the security of everything else. Work down the
list of five. Leave the long tail of forgotten forum accounts entirely alone — they will surface on their
own over the coming weeks, and saving them as they appear costs nothing.

## When it does not behave

| What you see | What to check |
|---|---|
| The extension ignores a login page | It is installed in the browser you are currently using, and the application itself is running |
| A saved entry is offered on one browser but not another | The extension is missing there; all four supported browsers read the same encrypted contents once installed |
| Nothing appears on a site that looks correct | The address is not the one the credential was saved against — treat the silence as a phishing warning, not a bug |
| Checkout pages stay empty | An identity or card record has not been created yet; passwords alone cannot complete those fields |
| The phone has different contents to the Mac | Confirm the same store is set up on that device, since the material is available across Windows, iOS and Android |

Tick the list once and the arrangement stops needing maintenance. Everything after the first hour is
simply saving credentials as you meet them, which is the entire ongoing cost of a mac password vault.
